- add tests
- create sample profile
- create developer documentation

- supported formats
- extraction

- provenance

- evidence handling

- capability taxonomy
- proven/adaptable/gap model
- opportunity preferences
- no-go rules

- validate existing GeM MCP
- build thin adapter if needed
- normalize results
- test current open bids

## Phase 5 - Opportunity Scout
- generic Skill
- intent interpretation
- candidate retrieval
- fit scoring
- ranking
- evidence-backed reporting
- human recommendation

Use actual historical project/tender material.
Measure relevance, false positives, missed opportunities, evidence quality, speed and explainability.

## Phase 7+
Only after validation: tender document analysis, bid/no-bid workflow, proposal workflows, learning from outcomes, monitoring and additional business lines/sources.
