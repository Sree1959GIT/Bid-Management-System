# BOI Workflow Model

## Generic lifecycle

```text
DISCOVER
  -> FILTER
  -> MATCH
  -> QUALIFY
  -> ANALYSE
  -> RECOMMEND
  -> HUMAN DECISION
  -> PROCESS
  -> OUTCOME
  -> LEARN
```

Not every business line needs every step.

## Engineering tender workflow
Potential stages:
- opportunity discovery
- technical fit
- compliance/eligibility
- system architecture
- BOM/vendor analysis
- engineering effort
- delivery feasibility
- costing
- risk
- bid/no-bid
- proposal

## Software services workflow
Potential stages:
- eligibility
- service scope
- technology fit
- team capability
- resource model
- delivery model
- estimation
- commercial model
- risk
- bid/no-bid
- proposal

## Workforce workflow
Potential stages:
- eligibility
- skill matrix
- headcount
- location
- availability
- statutory/compliance
- wage model
- deployment feasibility
- commercial model
- bid/no-bid

## Rule
Workflows are configuration and orchestration. They should not force every business line through the same sequence.
