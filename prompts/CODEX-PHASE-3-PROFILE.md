# Codex Phase 3 Prompt - Electronics & Automation Business Profile

Continue from the stable BOI foundation.

## Objective

Create the first real business-line profile for Electronics & Industrial Automation.

The profile must be editable by the business owner without changing application code.

## Include sections for
- business-line description
- core capabilities
- proven capabilities
- adaptable capabilities
- known gaps
- preferred sectors
- preferred buyers/customer types
- preferred opportunity types
- excluded opportunity types
- geography
- commercial preferences
- typical opportunity size
- delivery constraints
- eligibility constraints
- strategic priorities
- scoring weights
- fatal no-go conditions
- terminology and synonyms

Seed the profile with the broad themes supplied in the BOI specs, but clearly mark assumptions and placeholders.

## Important

Do not invent company facts.
Where real company knowledge is absent, create placeholders/TODOs and explain what evidence should populate the field.

## Acceptance

The opportunity-scout Skill can load this profile without code changes. Changing profile configuration alters evaluation behavior without requiring modification to core scoring code.
